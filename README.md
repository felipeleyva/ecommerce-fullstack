# 🛒 E-commerce Fullstack

## 📢 Descripción
Este proyecto es una aplicación de **E-commerce Fullstack** con una arquitectura escalable y segura.  
Desarrollado con **Java (Spring Boot) para el backend** y **React (Vite) para el frontend**, siguiendo las mejores prácticas de desarrollo y despliegue en la nube.

✅ **Backend:** Spring Boot, Spring Security, PostgreSQL, JWT, Docker  
✅ **Frontend:** React, Vite, Axios, React Router  
✅ **Cloud:** Google Cloud (Cloud Run, Cloud SQL), Docker  
✅ **Arquitectura limpia:** (Controller - Service - Repository - DAO)  
✅ **Autenticación segura:** Spring Security + JWT  
✅ **Pruebas unitarias y de integración**  
✅ **Gestión de pagos (próximamente con Stripe)**  
✅ **Despliegue en Google Cloud con Docker y Cloud Run**
